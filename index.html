    Author

  2. 02

    Generate

    playwright-bdd turns the feature files into Playwright specs — tag-based, data-driven and ready to run on any agent.

    terminal
    $ npx bddgen ✓ feature files → Playwright specs $ npx playwright test --grep @regression running 290 scenarios…
  3. 03

    Execute

    Page objects drive the UI. When a locator drifts, the rule-based self-healing layer recovers with a fallback strategy — and remembers it for the next run.

    run log
    ✓ open contract form ! locator not found — trying fallback strategies ↻ recovered · cached for next run ✓ submit contract ✓ status is "Active"

    Scale

  • Tag-based execution for smoke and regression across QA and UAT.
  • Scenario-count-based sharding (1–4 shards) on four self-hosted agent pools.
  • Shared feature artifact, intelligent retry and a failed-test re-run pass.
